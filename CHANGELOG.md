# Changelog

## 0.1.0 — 25 October 2026

Initial preview release: native Anki desktop workflow for generating an external
assistant prompt, validating/editing mixed Basic/Reversed/Typing/Cloze notes,
importing with duplicate skipping and one-step undo, and local Flashcards,
Learn, Test and Match practice. Optional packaged macOS Vision OCR reads files
and clipboard images locally. Includes research, install instructions and tests.
